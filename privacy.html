Privacy policy

Last updated: 17 November 2026

Who uses this app

assistant is a private, single-user assistant. Its only user is its owner, who runs it on the owner's own server. It is not offered to the public.

What data it accesses

Only with the owner's explicit consent, given through Google's sign-in screen:

  • Gmail: read-only access to the owner's messages. The app cannot send, change or delete mail.
  • Google Calendar: reading the owner's events, and creating an event only after the owner confirms it.
  • Google Tasks: reading the owner's tasks, and adding or completing a task only after the owner confirms it.

How the data is used

The data is used only to answer the owner's own requests, send the owner reminders, and prepare summaries for the owner. It is shown only to the owner, in a private Telegram chat.

Storage and sharing

Access tokens and the app's working data are stored on the owner's own server. The data is never sold, never used for advertising, and never shared with anyone other than the owner. To produce answers, the content the owner asks about is processed by the AI model the owner uses through their own subscription.

assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Open an issue at github.com/ObvMamut/assistant-oauth-pages.
