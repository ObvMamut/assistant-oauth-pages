assistant

assistant is a private, single-user personal assistant. It runs on its owner's own server and is used only by its owner, through a private Telegram chat.

With the owner's consent, it reads the owner's Gmail (read-only), Google Calendar and Google Tasks. It uses that data only to answer the owner's own questions, send the owner reminders, and add calendar events or tasks after the owner confirms each one.

It is not offered to anyone else and has no other users.
